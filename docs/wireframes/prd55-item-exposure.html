Пояснения — Wireframe

ЭлементПоле API / условиеПримечание
Вторая величина в карточке задания exposurePercent = выдач / попыток теста за окно FR-31. Стоит рядом с долей верных, потому что читается парой: «трудное и заезженное» и «трудное, но свежее» — разные диагнозы
Подпись «выдано N из M» deliveredCount / attemptsInWindow Абсолютные числа обязательны: 80% при пяти попытках и при пятистах — разные утверждения
Тон величины ≥ 70% — warning, иначе muted Порог показывает выработку банка, а не ошибку: красного тона здесь нет, потому что это не дефект задания
Тег «ещё в N тестах» otherTestsCount > 0 FR-32. Без него задание, растиражированное соседним тестом, выглядит редким
Строка «всего N показов» globalDeliveredCount Показывается только вместе с тегом: именно это число, а не долю по тесту, берёт вес выдачи
Прочерк вместо процента счётчик пуст (пакет старее 2026-09-12 либо данных ещё нет) «Не учтено» и «ноль показов» — разные вещи, и ноль здесь был бы ложью
Предупреждение под «Вопросов в тест» ожидаемая экспозиция = drawCount / poolSize ≥ 70% FR-33. Данных НЕ требует — считается из настроек, поэтому работает и на пустом тесте
Подсказка вместо баннера ожидаемая экспозиция < 70% Величина полезна всегда, тревога — нет: ниже порога это строка подсказки, а не баннер
Баннер в окне экспорта та же величина по худшей теме теста FR-33. Экспорт НЕ блокируется: это предупреждение, а не гейт
Экрана настройки поправки нет — Решение владельца: контроль экспозиции защищает банк и переключателя не имеет. Показываем только факты
