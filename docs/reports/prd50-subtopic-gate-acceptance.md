## Найдено и исправлено по ходу

**Проваленная подтема с нулевым результатом выглядела как «нет данных».** Тон применялся к
ЗАЛИВКЕ полосы, а при 0 % заливки нет вовсе — строка «Охрана труда 0 %» ничем не отличалась от
пустой. Теперь у проваленной подтемы красится и дорожка (`--ou-error-soft` на экране, `#fee2e2`
в отчёте), поэтому провал читается при любом значении. Правка в обоих шаблонах и в стилях
отчёта.

## Ловушка стенда, которую надо знать при выкате

Шаблон `certification` веб-хост читает НЕ из исходников репозитория, а из
`uploads/templates/certification` (строка `templates.source_path`), то есть из загруженной
копии. Пока шаблон не перезалит, правки макетов и стилей в нём не видны: на демо-тесте разрез
печатался без окраски именно поэтому, хотя данные несли исход. Шаблон `default` в этой сессии
читался прямо из worktree, и на нём всё видно.

Следствие для выката: одной установки кода мало — шаблон `certification` на каждом стенде
нужно перезалить, иначе окраска строк и надпись порога у него не появятся.
